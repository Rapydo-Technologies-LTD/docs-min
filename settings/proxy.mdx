# Proxy

Configure proxy servers for Rapydo to connect through when accessing external resources or database instances.

## Overview

The Proxy settings tab allows you to define proxy servers that Rapydo uses for outbound connections. This is useful when your infrastructure requires traffic to route through specific network proxies.

## Adding a Proxy

Click **Add New Proxy** to open the configuration form.

### Configuration Fields

**Name** — A friendly name to identify this proxy in the list.

**Address** — The proxy server address (hostname or IP with port).

### Actions

- **Save** — Add the proxy configuration
- **Cancel** — Discard changes and close the form

## Managing Proxies

The proxy list displays all configured proxies with their names and addresses.

**Table Settings** — Customize which columns are displayed in the proxy list.

Use the action menu on each row to edit or delete existing proxy configurations.
